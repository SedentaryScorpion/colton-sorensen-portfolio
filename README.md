# Colton Sorensen — portfolio site

This is the approved, dependency-free static website. Deploy the entire folder to a static host such as Netlify, Vercel, Cloudflare Pages, or GitHub Pages.

## Before publishing

- Replace or expand the photos in `assets/` as new work is ready.
- Update the social links and add an email/contact method in `index.html` if desired.
- Replace the legacy Google Sites links in `script.js` with dedicated new-site pages or hosted reels once those are ready.
- Point `www.coltonsorensen.com` at the new host after deployment.

The design is built from the existing portfolio photos and content, with a new visual system and a responsive mobile navigation.
